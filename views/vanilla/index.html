Build Real Things With AI

A learning scaffold for designers who want to use Claude Code to build actual applications—not just prototypes that dead-end.

The Problem

You're a designer. You've seen what AI coding tools can do. You want in. But the code works until it doesn't, and you can't debug it. Terms like "services layer" and "state management" feel like a foreign language.

The Solution

Investiture is engineering knowledge pre-loaded into a scaffold your AI can read. Work inside a system with guardrails built in. You don't have to become an engineer—just build inside structure that already knows the rules.

What You'll Learn

Separation of concerns. Service abstraction. Design tokens. Content separation. The shape of real codebases—folders that make sense, files that have one job. Not from a tutorial. From doing.

Who It's For

UX designers who want to build, not just wireframe. Design technologists leveling up their AI-assisted workflow. Anyone who's been "vibe-coding" and wants to understand why things work.

Architecture Layers

🎨

Design System

Tokens, themes, and component definitions. Swap entire visual systems without touching code.

📝

Content Layer

All user-facing strings in one place. i18n-ready. CMS-swappable.

⚙️

Core Logic

Pure functions and state management. Framework-agnostic. Testable.

🔌

Services

Auth, database, AI - all wrapped. Swap Supabase for Firebase in one file.
